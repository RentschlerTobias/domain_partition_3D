## The pipeline (measured end to end)

```
dtOO (parametric machine, 30 cV_ru values)
  -> case/mesh.msh          hybrid mesh: tets + BL prisms + blade O-grid hexes
  -> tet_prep_v5.py         reduced domain (blade O-grid + BL cut), feature
                            edges = patch boundaries, gmsh interior mesh
  -> run_algohex.py         AlgoHex HexMeshing (-n 2000), 25-50 min / core
  -> beam_collapse.py       sheet collapse via beam search (w16 d6, struct
                            guard), ~1.5 min  <- replaces the greedy cleanup
  -> tfi.py / export_sample.py   transfinite refill + sample.npz export
```

- Entry: `stack-run hexblock <mesh> --tag test` works on branch
  `data_generation` (master is broken for this chain).
- Run scripts: `/work/perturb/run_one.sh` (single perturbation run),
  `/work/beam/run_all.sh` (beam collapse batch).
- The blade goes back in AFTER generation (`ogrid_extrude.py`, conforming,
  26 blocks on smoke; `reattach.py` fixes the layer welding).

## Key findings (all documented in docs/decisions/)

1. **Topology is not a function of the geometry** (gmsh nondeterminism,
   2-tet differences flip outcomes); old labels were noise (12/22/75 for
   the SAME geometry). Fix: beam search over collapse orders — 17/17 runs
   land on the canonical 12-block / 12-cuboid topology (`3c7430d6`).
   Doc: `2026-09-28-beam-collapse-relabelling.md`.
2. **Cut-set (block-level) sheet search cannot replace it**: unions over
   the 24 separatrix sheets plateau at 22/25 blocks; the welds are not
   expressible as dual-adjacency unions. `sheet_beam.py` stays as an
   audit tool only. Doc: `2026-09-30-cutset-search-not-a-collapse-...`.
3. **LE/TE feature edges: rejected.** They are parametric curves
   (u=0/u=1, closeU=true), not creases (max wall dihedral 17 deg); adding
   them diverged the full domain (2.5 d run) and crashed HexEx reduced.
   The two LE/TE-parallel singularity arcs are normal field topology.
   Doc: `2026-10-03-le-te-feature-edges-rejected.md`.
4. **Ring defect (95 deg kink at the hub O-ring): fixed at the source**
   by ring densification (`tet_prep_v5.py --remesh-ogrid 0.030`):
   12/12 cuboids, 0 kinks > 30 deg, 0 inverted. Validated on base_a only —
   batch over the 13 perturbation samples still pending.
5. The first extraction (singularity tracing -> 24 sheets -> 84 raw blocks)
   is deterministic and bit-stable across 13 geometries (smoke, a
   different machine: 4 arcs / 18 sheets / 22 blocks).
