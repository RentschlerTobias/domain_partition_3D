## 1. What the project is
`hexdp` (this repo, `/opt/stack/domain_partition_3D`, package in `src/hexdp`, editable install in `/opt/venv-sci`)
partitions arbitrary 3D geometries into hexahedral BLOCK structures. Purpose: training data for the owner's
flow-matching / transformer model (input: closed oriented boundary point cloud with normals -> output: block
structure); a pretraining dataset others can fine-tune. Also an MCP server (`hexdp mcp`, 22 tools) so an LLM agent
can block geometries (see README section "hexdp as an MCP server").

Main pipeline for general geometries: tet mesh with feature tags -> AlgoHex (frame field + integer-grid map, hours)
-> `hexdp.ops.beam_collapse` (beam search over sheet collapses -> coarse blocks, cleanup, untangle, snap) -> TFI
-> exporters (`vtk`, `msh`, `dataset` = sample.npz training format). Other strategies: `sweep`/`cgrid` (CAD,
pythonOCC), `polycube` (evocube), `composite` (building blocks, used for the tistos structural runner).
